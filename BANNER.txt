🚀 DÉMARRAGE RAPIDE:

   1. Initialiser le projet:
      $ python scripts/init_project.py
      
   2. Entraîner le modèle:
      $ make train
      
   3. Lancer l'application:
      $ make run
      
   4. Ouvrir dans le navigateur:
      → http://localhost:5000
